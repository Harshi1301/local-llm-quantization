RESULTS LOG - Local LLMs on CPU-only laptop (i7-1165G7, 15.7 GB RAM, no dedicated GPU)
Ollama 0.40.15, models in D:\OllamaModels

METHOD
- Temperature 0, seed 42, context 4096, 100% CPU.
- Each run = separate API call (no shared context, same effect as /clear).
- Speed prompt: "List the eight planets of the solar system in order from the Sun, and give one short fact about each."
  Eval rate only (generated tokens / generation time), 3 runs, average +- sample std dev.
- RAM: model size in memory (ollama ps / /api/ps), GB = 1000^3.
- Accuracy: 10 questions with answer key (accuracy_questions.txt), prefix "Answer with only the final answer, no explanation."
  Auto-marked by key text, answers also checked by hand. 1 question = 10 percentage points.
- Scripts: run_speed.ps1, run_accuracy.ps1 (folder: Documents\Harshita\Seminar\claude)

MAIN FINDINGS
1. 4-bit (Q4_K_M) is 1.5-2.6x faster and uses 63-66% less RAM than FP16 in all 3 families.
2. 8-bit (Q8_0) gives 1.3-1.5x speed and 43-45% less RAM.
3. Accuracy on the 10-question set stayed at 8-9 / 10 for every setup: no measurable loss.
   All wrong answers are in the two-step reasoning questions (Q8, Q10).
4. Speed x RAM is roughly 10-20 GB/s -> generation is mostly limited by memory bandwidth.

CAVEATS FOR THE PAPER
- 10 questions: one question = 10 points; 1-question differences (Qwen 8 vs 9) are noise.
- Llama Q8_0 was measured twice (3.18 first, 4.14 re-run); first considered disturbed. Both kept in log.
- Qwen Q4_KM and Gemma Q4_KM: answer length differs between run 1 and runs 2-3 even at temp 0, seed 42.
- Speed spread is about +-0.4 for several quantized runs; throttling suspected but not shown.
- Single laptop, CPU only, one prompt for speed, 3 runs per setup.
